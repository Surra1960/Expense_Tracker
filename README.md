# 📊 Expense Tracker Web App

A simple Expense Tracker built using HTML, CSS, and JavaScript. This project helps users manage their daily expenses by allowing them to add, display, search, and delete expense records.

---

## 🚀 Features

- Add new expenses with title, amount, category, date, and recurring status
- Display all stored expenses dynamically
- Search expenses by title or category
- Delete individual expenses
- Input validation for better data accuracy
- Simple and interactive user interface

---

## 🛠️ Technologies Used

- HTML  
- CSS  
- JavaScript (ES6)

---

## 📂 Project Structure

- `index.html` – Main structure of the app  
- `project4.css` – Styling  
- `expense.js` – Expense model/class  
- `ExpenseManager.js` – Handles expense operations  
- `project4.js` – Main application logic
